# 🎵 Music Theory

A fast-paced top-down survival game built with **Unity** and **C#**, where music becomes your weapon.

Fight against endless waves of enemies using a spinning musical note while surviving for as long as possible. This project is currently in **Beta**, serving as the foundation for many planned gameplay mechanics and content updates.

# 🎮 Gameplay

- Control your character in a top-down arena.
- Enemies continuously spawn and chase the player.
- Attack automatically using a spinning musical note.
- Survive as long as possible while defeating incoming enemies.
